# Nomenclature Cheat Sheet (Step 4b)

A starter set of domain terms, grouped by the kind of image. Use it to find the
word a specialist would use for a part, then gloss it in plain language. It is
a prompt for your memory, not a closed list: if the right term isn't here, use
it anyway; if you aren't sure a term is right, say so instead of inventing one.

Each entry: **term** — plain gloss.

## Heraldry, emblems, badges, logos
- **escutcheon / shield** — the shield shape the design sits on
- **laurels / wreath** — paired leafy branches curving up the sides (victory, honor)
- **roundel** — a circular badge or disc
- **cartouche** — an ornamental frame (often scroll-edged) around a name or panel
- **banner / scroll / ribbon** — the ribbon strip that carries a motto
- **crest** — the element on top of the shield (in strict heraldry; loosely, the whole badge)
- **supporters** — the figures or animals standing either side of the shield
- **charge** — any symbol placed on the shield
- **wordmark** — the name set as a logo in type
- **lettermark / monogram** — initials used as the mark
- **lockup** — a fixed arrangement of symbol + wordmark (+ tagline) used as one unit
- **clear space** — the empty margin kept around a mark

## Posters, print, editorial layout
- **masthead** — the fixed title block at the top (magazines, newspapers)
- **headline / title** — the biggest line of type
- **kicker / overline** — a short small line set just above the headline
- **deck / subhead** — the secondary line under the headline
- **credit line / imprint** — who issued, printed, or sponsored it
- **copy block / type panel** — the zone reserved for text
- **border / margin** — the unprinted or framing band around the image
- **bleed** — image running right off the trimmed edge
- **registration** — how accurately separate ink layers line up
- **spot color / color separation** — each ink printed as its own flat layer
- **halftone** — dots that fake tone; **benday dots** — the comic-book version

## Typography
- **display face** — a typeface built for big sizes and personality
- **geometric sans** — sans-serif built from circles and straight lines (Futura-like)
- **slab serif** — heavy, block-like serifs
- **tracking / kerning** — spacing across a word / between a specific letter pair
- **cap height / x-height** — height of capitals / of lowercase letters
- **ligature** — two letters joined into one glyph
- **hand-lettered** — drawn letters, not a typeface

## Character and creature design
- **silhouette** — the solid outline shape; what reads at a glance
- **silhouette break** — a feature that pokes out of the outline and makes it recognizable
- **shape language** — the dominant shape family (round = friendly, square = sturdy, triangle = threat)
- **proportions / head count** — body height measured in heads
- **gesture / line of action** — the main curve running through the pose
- **focal read** — the one detail the eye is meant to land on (face, weapon, emblem)
- **value grouping** — how light/dark areas cluster to separate parts
- **secondary / tertiary shapes** — mid-size and small detail shapes on top of the primary mass

## Armor, costume, props
- **pauldron** — shoulder armor plate
- **gorget** — throat/neck guard
- **vambrace** — forearm guard
- **cuirass / breastplate** — torso armor
- **tasset** — hip/thigh plates hanging from the waist
- **greave** — shin guard
- **tabard / surcoat** — cloth worn over armor, often with heraldry
- **pommel / crossguard / fuller** — sword end knob / hand-guard bar / groove along the blade
- **trim / piping** — the edge band on a garment or plate

## UI / UX
- **hero** — the large top-of-page banner area
- **nav bar / nav rail** — horizontal / vertical navigation strip
- **card** — a bounded container for one item
- **chip / pill / tag** — small rounded label or filter
- **modal / dialog** — a window over the page that demands attention
- **toast / snackbar** — a brief pop-up notification
- **CTA (call to action)** — the primary button
- **gutter / padding** — space between / inside elements
- **affordance** — a visual cue that something is clickable or draggable
- **empty state** — what shows when there's no content yet

## Landscape and environment
- **foreground / midground / background** — the three depth bands
- **repoussoir** — a dark framing shape in the foreground that pushes the eye in
- **atmospheric perspective** — distance shown by lighter, cooler, lower-contrast color
- **mesa / butte** — flat-topped rock landform (wide / narrow)
- **escarpment / cliff band** — a long steep face
- **ledge / bench / terrace** — a flat step in a slope
- **talus / scree** — the slope of broken rock under a cliff
- **gorge / inner canyon** — the narrow deepest cut
- **horizon line / skyline** — where land meets sky
- **establishing shot / vista** — a wide view that sets the place

## Architecture and interiors
- **facade** — the front face of a building
- **cornice** — the projecting ledge along the top
- **pilaster** — a flat column set against a wall
- **arcade / colonnade** — a row of arches / columns
- **setback / ziggurat** — the stepped-back upper floors of a tower (Art Deco)
- **fenestration** — the pattern of windows
- **wainscot** — paneling on the lower part of a wall
- **coffered ceiling** — a ceiling of sunken square panels

## Photography and lighting
- **key / fill / rim (back) light** — main light / shadow-softener / edge light behind the subject
- **catchlight** — the light's reflection in the eyes
- **bokeh** — the blur quality of out-of-focus areas
- **depth of field** — how much of the scene is sharp
- **high-key / low-key** — mostly bright / mostly dark lighting
- **split / Rembrandt / butterfly light** — named face-lighting patterns (half-lit / cheek triangle / shadow under nose)
- **leading lines** — lines in the scene that guide the eye

## 3D render / materials
- **PBR** — physically based materials (albedo, roughness, metalness)
- **albedo** — the base color with no lighting
- **roughness** — how blurry vs mirror-like reflections are
- **subsurface scattering** — light glowing through skin, wax, leaves
- **ambient occlusion** — soft darkening in creases and contact points
- **bevel / chamfer** — a rounded / angled edge instead of a razor-sharp one
- **topology** — the flow of the mesh's polygons
- **HDRI** — a 360° photo used to light the scene
